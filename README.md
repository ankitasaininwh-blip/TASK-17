# TASK-17
 JavaScript Promise-based Divide Function

## Project Title

Promise-based Division Function

## Objective

The objective of this project is to create a JavaScript function that
performs division using Promises.

The function handles division by zero using Promise rejection and
displays an appropriate error message.

## Features

- Performs division of two numbers.
- Uses a Promise to handle the division operation.
- Uses an arrow function.
- Resolves the Promise when division is successful.
- Rejects the Promise when the second number is zero.
- Handles errors using catch().
- Demonstrates at least five test cases.
- Displays results in the browser.
